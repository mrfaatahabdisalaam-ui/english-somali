# English → Somali Premium Membership

Nidaam mobile-first ah: user login phone, $3/30 maalmood, manual payment approval, admin dashboard, video upload iyo English/Somali subtitles synchronized.

## Run
1. Ku rakib Node.js.
2. `npm install`
3. `ADMIN_PASSWORD=PASSWORD_KAAGA SESSION_SECRET=SECRET_KAAGA npm start`
4. Fur `http://localhost:3000`
5. Admin: `http://localhost:3000/admin.html`
